
| Yêu cầu                                        | Mô tả                                                                                         | Đoạn mã Java minh họa |
|------------------------------------------------|----------------------------------------------------------------------------------------------|------------------------|
| **Thuộc tính của lớp**                         | Xác định các thuộc tính cơ bản: `id`, `name`, `department`, `salary`.                       | ```java<br/> int id;<br> String name;<br> String department;<br> double salary;<br>``` |
| **Constructor**                                | Viết constructor có tham số để khởi tạo thông tin nhân viên.                                | ```java<br>public Employee(int id, String name, String department, double salary) {<br>    this.id = id;<br>    this.name = name;<br>    this.department = department;<br>    this.salary = salary;<br>}<br>``` |
| **Phương thức hiển thị thông tin (`displayInfo()`)** | Viết phương thức hiển thị thông tin nhân viên bao gồm: mã, tên và phòng ban.               | ```java<br>public void displayInfo() {<br>    System.out.println("ID: " + id + ", Name: " + name + ", Department: " + department);<br>}<br>``` |
| **Getter và Setter**                           | Viết getter và setter cho thuộc tính `salary` để thay đổi lương nếu cần.                   | ```java<br>public double getSalary() { return salary; }<br>public void setSalary(double salary) { this.salary = salary; }<br>``` |
| **Phương thức tăng lương (`increaseSalary(double percentage)`)** | Viết phương thức để tăng lương nhân viên dựa trên phần trăm (`percentage`) nhập vào.       | ```java<br>public void increaseSalary(double percentage) {<br>    this.salary += this.salary * (percentage / 100);<br>}<br>``` |
| **Khởi tạo và sử dụng đối tượng**               | Viết đoạn mã trong hàm `main` để tạo đối tượng nhân viên (`Employee`) và thực hiện các thao tác. | ```java<br>public static void main(String[] args) {<br>    Employee emp = new Employee(1, "John Doe", "IT", 5000);<br>    emp.displayInfo();<br>    emp.increaseSalary(10);<br>    System.out.println("Updated Salary: " + emp.getSalary());<br>}<br>``` |
