1. Tính đóng gói là gì? Tại sao tính đóng gói lại quan trọng trong lập trình đối tượng?

- Là một trong những nguyên tắc quan trọng của OOP. Nó là kỹ thuật bảo vệ dữ liệu bằng cách ẩn giấu thông tin bên trong một lớp và chỉ cho phép truy cập thông qua các phương thức được định nghĩa sẵn.

 - Tại sao tính đóng gói quan trọng?
   - Ngăn chặn truy cập trực tiếp vào các thuộc tính của lớp.
   - Chỉ cho phép chỉnh sửa dữ liệu thông qua các phương thức `getter` và `setter`.
   - Có thể thay đổi cách xử lý dữ liệu mà không ảnh hưởng đến phần còn lại của chương trình.
   - Giúp mã nguồn dễ đọc, dễ hiểu và dễ kiểm soát hơn

---

 2. Làm thế nào để áp dụng tính đóng gói trong Java?

- Tính đóng gói được thực hiện bằng cách:
  1. Định nghĩa các thuộc tính của lớp với phạm vi truy cập `private`.
  2. Cung cấp các phương thức `getter` và `setter` để truy cập và thay đổi giá trị thuộc tính.
  3. Sử dụng từ khóa `public`, `protected`, `private` để kiểm soát quyền truy cập.

-  Giải thích về Getter và Setter:
    - Getter: Là phương thức giúp lấy giá trị của thuộc tính 
    - Setter: Là phương thức giúp thay đổi giá trị của thuộc tính.

 3. Ví dụ về tính đóng gói trong Java
```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        if (name != null && !name.trim().isEmpty()) {
            this.name = name;
        } else {
            System.out.println("Tên không hợp lệ!");
        }
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age > 0) {
            this.age = age;
        } else {
            System.out.println("Tuổi phải lớn hơn 0!");
        }
    }

}
```

```java 
public class Main {
    public static void main(String[] args) {
        Person person = new Person("Nguyen Van A", 25);
        
        person.setName("Tran Thi B");
        person.setAge(30);

        person.displayInfo();
        
        person.setName("");   
        person.setAge(-5);   
    }
}
```

4.  Lợi ích của việc sử dụng tính đóng gói trong việc bảo vệ dữ liệu và kiểm soát quyền truy cập

- Bảo vệ dữ liệu
  - Ngăn chặn các thay đổi không mong muốn đối với dữ liệu bằng cách kiểm soát quyền truy cập.
  - Tránh tình trạng dữ liệu bị sửa đổi trực tiếp mà không thông qua kiểm tra hợp lệ.

- Kiểm soát quyền truy cập
  - Có thể giới hạn phạm vi truy cập bằng các từ khóa `private`, `protected`, `public`.
  - Chỉ cho phép thay đổi dữ liệu thông qua các phương thức setter có kiểm tra tính hợp lệ.

- Tăng tính linh hoạt và dễ bảo trì
  - Khi cần thay đổi cách xử lý dữ liệu, chỉ cần thay đổi trong lớp mà không ảnh hưởng đến phần còn lại của chương trình.
  - Dễ dàng mở rộng hoặc sửa đổi mà không làm ảnh hưởng đến các phần khác của hệ thống.
