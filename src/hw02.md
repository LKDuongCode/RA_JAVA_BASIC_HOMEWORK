
1. Kế thừa là gì? Nó giúp ích gì trong lập trình hướng đối tượng?

- Kế thừa là một trong những nguyên lý cơ bản của lập trình hướng đối tượng (OOP), cho phép tạo ra các lớp mới từ các lớp đã có, giúp tái sử dụng mã nguồn và tạo ra các quan hệ giữa các đối tượng. Trong Java, kế thừa được thực hiện bằng cách sử dụng từ khóa `extends`.

- Lợi ích của kế thừa:
  - Tái sử dụng mã nguồn
  - Dễ dàng mở rộng: Có thể thêm chức năng mới vào lớp con mà không ảnh hưởng đến lớp cha.
  - Tổ chức code tốt hơn

---

2. Sự khác biệt giữa Kế thừa và Bao đóng (Encapsulation) trong Java

| Đặc điểm         | Kế thừa (Inheritance) | Bao đóng (Encapsulation) |
|-----------------|----------------------|--------------------------|
| **Khái niệm**    | Một lớp con kế thừa các thuộc tính và phương thức từ lớp cha. | Bảo vệ dữ liệu bằng cách đóng gói trong lớp và sử dụng `getter/setter`. |
| **Mục đích**    |  tái sử dụng mã nguồn và mở rộng chức năng. | Kiểm soát truy cập vào dữ liệu của lớp. |
| **Cách thực hiện** | Dùng từ khóa `extends`. | Dùng từ khóa `private`, `protected`, `public` và phương thức `getter/setter`. |

3. Ví dụ về Kế thừa trong Java

```java
class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void makeSound() {
        System.out.println("Some generic animal sound");
    }

    public void displayInfo() {
        System.out.println("Tên động vật: " + name);
    }
}
```
``` java
class Dog extends Animal {
    private String breed;

    public Dog(String name, String breed) {
        super(name); 
        this.breed = breed;
    }


    @Override
    public void makeSound() {
        System.out.println("Woof Woof");
    }

    public void showBreed() {
        System.out.println("Giống chó: " + breed);
    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Dog myDog = new Dog("Buddy", "Golden Retriever");
        myDog.displayInfo();  
        myDog.makeSound();    
        myDog.showBreed();     
    }
}
```

4. Lợi ích và hạn chế của kế thừa trong Java

- Lợi ích của kế thừa
  - Tái sử dụng mã nguồn : Giảm thiểu lặp lại code.
  - Dễ bảo trì : Nếu cần sửa đổi logic, chỉ cần thay đổi ở lớp cha.
  - Hỗ trợ tính đa hình (Polymorphism) : Giúp thiết kế hệ thống linh hoạt.

- Hạn chế của kế thừa
  - Lớp con phụ thuộc vào lớp cha : Nếu lớp cha thay đổi, lớp con cũng bị ảnh hưởng.
  - Lạm dụng kế thừa có thể làm mã nguồn phức tạp hơn.
  - Không hỗ trợ đa kế thừa trực tiếp trong Java : Một lớp con chỉ có thể kế thừa từ một lớp cha duy nhất. (sử dụng interface để hỗ trợ đa kt)
